Intro to Neural Networks

Tags: neural networks, deep learning, ML basics

At its core, a neural network is just a stack of simple functions that learn, by example, how to turn an input into a useful output — no one hand-codes the rules.

The building block: a single neuron

One neuron takes several numeric inputs, multiplies each by a learned "weight", adds them up plus a bias term, and passes the result through an activation function that decides how strongly the neuron "fires".

output = activation(w1*x1 + w2*x2 + ... + wn*xn + bias)

Common activation functions: ReLU (zero out negatives, keep positives as-is), sigmoid (squash to 0–1), and tanh (squash to -1–1).

Stacking neurons into layers

  • Input layer — the raw features (pixels, words, numbers)
  • Hidden layer(s) — where the actual pattern-learning happens
  • Output layer — the prediction (a class label, a probability, a number)

"Deep" learning just means there are multiple hidden layers stacked between input and output.

How it actually learns

Training is a loop:

  1. Forward pass — push an input through the network to get a prediction.
  2. Loss — measure how wrong the prediction was, with a loss function.
  3. Backpropagation — work backward through the network to figure out how much each weight contributed to the error.
  4. Update — nudge every weight slightly in the direction that reduces the error (gradient descent).

Repeat this over thousands of examples, and the weights gradually settle into values that generalize to new, unseen inputs.

A neural network isn't "intelligent" in any human sense — it's a very large, differentiable function being nudged, one gradient step at a time, toward fewer mistakes on the training data.

Why this matters for detection tasks

For something like deepfake or misinformation detection, the same idea applies: the network is shown many real and fake examples, learns which patterns in the pixels (or the text) correlate with "fake", and encodes that as weights — nobody writes an explicit rulebook for "what a deepfake looks like".

Takeaway

Every neural network, no matter how large, is the same three ideas repeated: weighted sums, non-linear activations, and gradient-based learning from labeled examples.
